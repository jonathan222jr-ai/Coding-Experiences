# Student Starter Package

Implement `lowering.py` only.

## Run the starter
```bash
python main.py --dump-ir
python main.py --run-ir
```

## Running the integrated grading tests
This package includes the 10 official grading-style tests in `tests/test_lab4.py`.

Run them with:
```bash
pytest tests/test_lab4.py
```

The starter package is expected to fail these tests until you complete `lowering.py`.
