# Data Structures (C++)

CSE 100 labs — classic data structures implemented from scratch in C++, each building
with its own Makefile.

Work centres on binary search trees and the operations around them: insertion,
traversal, search, and deletion, along with the supporting file I/O and test drivers
each lab required.

Each lab directory is self-contained:

```bash
cd Lab06
make
```

Compiled binaries and submission archives have been removed — only source, Makefiles,
and test fixtures are kept.
