# Web Development (CSE 108)

Full-stack labs pairing hand-written HTML/CSS/JavaScript front ends with Python back
ends, working up from static pages to a database-backed application.

| Lab | Focus |
|---|---|
| `Lab01` | Python fundamentals |
| `Lab02`–`Lab03` | HTML and CSS layout |
| `Lab05` | Splitting a project into a `Frontend/` and a Flask `Backend/` |
| `Lab07`–`Lab08` | Flask with SQLAlchemy models, WTForms, and database seeding (`populate_db.py`) |
| `live_chat_hub` | Socket.IO chat — the standalone version lives in [`web-apps/live-chat-hub`](../../web-apps/live-chat-hub) |

The course final project, a real-time multiplayer Blackjack game, is published
separately as [`web-apps/blackjack-multiplayer`](../../web-apps/blackjack-multiplayer).

Submission `.zip` archives have been unpacked or removed so the source is browsable
directly.
