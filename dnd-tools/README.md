# D&D Tools

Standalone tools written for running a D&D 5e game.

| File | Description |
|---|---|
| `greek_npc_roller.html` | Self-contained NPC generator for a Greek-myth setting. Rolls names, traits, and hooks; styled as clay-and-papyrus with a Greek key border. Open the file in a browser — no build step or dependencies. |
| `elemental_cataclysm_generator.py` | Blender script that procedurally builds an elemental D&D 5e creature from fire, water, earth, and air parts, with generated shader materials. Paste into Blender's Script Editor and run. |
