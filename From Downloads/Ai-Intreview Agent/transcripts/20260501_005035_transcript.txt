▸ AGENT: FULLSTACK  (5044ms)
  Task: type function groupBy so it returns record, runtime?

  ANSWER: groupBy takes an array and a key function, returns a Record where keys are whatever the key function returns and values are arrays of matching items. Runtime is O(n) — single pass through the array.
  
  ```typescript
  function groupBy<T, K extends string | number | symbol>(
    arr: T[],
    keyFn: (item: T) => K
  ): Record<K, T[]> {
    return arr.reduce((acc, item) => {
      const key = keyFn(item);
      if (!acc[key]) acc[key] = [];
      acc[key].push(item);
      return acc;
    }, {} as Record<K, T[]>);
  }
  
  // Usage
  const users = [{ role: "admin", name: "Alice" }, { role: "user", name: "Bob" }];
  const grouped = groupBy(users, u => u.role);
  // { admin: [...], user: [...] }
  ```
  
  TRADEOFF: Using `K extends string | number | symbol` is the safe constraint for Record keys — you could loosen it to just `string` if you want simpler types, but you lose flexibility. Also `Map` would be cleaner if keys are objects, since Record only works with primitives as keys.
