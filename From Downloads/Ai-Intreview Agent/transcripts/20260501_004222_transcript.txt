  Task: kesequence from a react component mounting to the express route

  ANSWER: When a React component mounts, it fires `useEffect`, which calls `fetch` or axios to hit your Express route. The request goes through any middleware (CORS, auth, body-parser), hits the route handler, queries the DB, and sends back JSON. React then updates state with the response, triggering a re-render.
  
  ```typescript
  // React side
  useEffect(() => {
    const fetchData = async () => {
      const res = await fetch('/api/users');
      const data = await res.json();
      setUsers(data);
    };
    fetchData();
  }, []);
  
  // Express side
  app.use(cors());
  app.use(express.json());
  
  app.get('/api/users', async (req, res) => {
    const users = await db.query('SELECT * FROM users');
    res.json(users);
  });
  ```
  
  Full sequence:
  1. Component mounts → `useEffect` runs
  2. HTTP GET fires
  3. Express middleware chain runs
  4. Route handler executes
  5. DB query resolves
  6. `res.json()` sends response
  7. React state updates → re-render
  
  TRADEOFF: `useEffect` for data fetching works but causes a waterfall. Using React Query or SWR handles caching, loading states, and deduplication way more cleanly — I'd reach for that on anything beyond a toy project.
