Then I'd trace the data flow: network tab → state → render, because the bug is usually in one of those three spots. My bet is either the response shape changed (like `data.items` instead of `data`) or there's a state update timing issue.
  
  ```typescript
  // Check what you're actually getting
  const fetchItems = async () => {
    const res = await fetch('/api/items');
    const json = await res.json();
    
    console.log('Raw response:', json); // is it { data: [] } or []?
    
    // Common mistake: expecting array but getting wrapped object
    setItems(json.data ?? json); // handle both shapes
  };
  
  // Also verify in component
  console.log('items state:', items, 'type:', typeof items);
  ```
  
  ```
  Network Tab → Check response body, not just status

  Render → Add null checks, maybe items is undefined not []
  ```
  
  TRADEOFF: You could add response interceptors globally to catch shape mismatches early, but that adds abstraction — sometimes just fixing the one call is faster in prod.
