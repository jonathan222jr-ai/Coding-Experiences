// execution model

Two Waves.
Three Agents.

Classifier and SpeedTip fire in parallel (Wave 1). The primary answer agent fires immediately after routing (Wave 2). Total latency: ~2s.

01

Speak or Type

Use --loop voice mode during the live interview or paste the question into the web UI. Both flow into the same orchestrator.

02

Wave 1 — Triage (parallel)

Classifier detects the question type. SpeedTip fires a 1-liner coaching cue. Both run simultaneously on Haiku.

03

Wave 2 — Answer (routed)

The right Sonnet agent fires based on the classifier output. Behavioral → STAR. Coding → TypeScript solution. JS → concept breakdown. Etc.

04

Self-Improvement

Every 20 questions, the improvement loop reads task history, identifies weak agents, and rewrites their system prompts automatically.

orchestrator.py — routing table
# Question type → agent
ROUTING = {
  "behavioral": BehavioralAgent,
  "coding":     CoderAgent,
  "js_concept": JSExplainerAgent,
  "fullstack":  FullstackAgent,
  "debugging":  DebuggerAgent,
  "motivation": MotivationAgent,
}

# Wave 1 — parallel Haiku triage
with ThreadPoolExecutor(max_workers=2) as ex:
  f_cls = ex.submit(classifier.call, q)
  f_tip = ex.submit(speed_tip.call, q)

# Wave 2 — routed Sonnet answer
agent = ROUTING[classification["type"]]
answer = agent.call(question)

# Auto-improve every 20 questions
if task_count % 20 == 0:
  Thread(target=run_improvement_cycle).start()
