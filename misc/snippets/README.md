# Snippets

Loose working files kept as a record of how the email-scanner add-in took shape.

These are intermediate TypeScript modules — `featureExtractor`, `ruleEngine`,
`riskScorer`, `scannerEngine`, `EmailModel`, and two takes on the `taskpane` — from
before the layering settled. The finished versions live in
[`office-addins/fraud-email-scanner`](../../office-addins/fraud-email-scanner), and a
parallel Python implementation with tests is in
[`security-tools/email-scanner-python`](../../security-tools/email-scanner-python).

Kept for the diff between drafts and the final structure, not as working code.
