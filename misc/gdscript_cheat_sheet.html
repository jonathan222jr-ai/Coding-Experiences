VariablesDeclaring & typing
Dynamic (flexible)
var health = 100 var name = "Hero" var alive = true
Static (type-safe)
var damage: int = 15 var speed: float = 3.5 var label: String = "Hi"
Inferred static (walrus-style)
var damage := 15
Godot infers int — type is still static
Constant
const GRAVITY = -9.81
Inspector-editable
@export var speed: float = 5.0
Core data types
bool — true / false  |  int — whole numbers  |  float — decimals  |  String — text  |  Vector2 / Vector3 — coordinates
Casting & MathType conversion & operators
Convert types
str(42) # → "42" int(3.9) # → 3 (truncates!) float(5) # → 5.0
Arithmetic shortcuts
health += 20 # add health -= 10 # subtract health *= 2 # multiply health /= 4 # divide
Random numbers
randf() # 0.0 – 1.0 randf_range(0, 1) # float in range randi_range(140,210) # int in range
ConditionsIf / elif / else
if health <= 0: print("You died!") elif health < 50: print("Injured") else: print("Healthy")
Comparison operators
== # equal != # not equal > < >= <=
Combining conditions
if alive and health > 0: if dead or health == 0:
MatchSwitch-style branching
match unit_alignment: Alignment.ALLY: print("Hello, friend!") Alignment.NEUTRAL: print("I come in peace!") Alignment.ENEMY: print("Taste my wrath!") _: print("Who art thou?")
_: is the default / fallback case
FunctionsDefine & call
Basic
func jump(): print("JUMP!")
With parameters & return
func add(num1: int, num2: int) -> int: return num1 + num2 var result = add(3, 5) # → 8
Built-in Godot functions
func _ready(): # runs on start func _input(event): # runs on input func _process(delta):# runs every frame
Underscore prefix = called by engine, not by you
ArraysLists of elements
var items = ["Potion", "Feather"] var typed: Array[String] = ["Sword"] items[0] # "Potion" (index 0) items[1] = "Sock" # change element items.append("Shield") # add to end items.remove_at(0) # remove at index
Loop through array
for item in items: print(item)
DictionariesKey → value pairs
var players = { "Crook": 1, "Villain": 35, "Boss": 100, } players["Villain"] # → 35 players["Villain"] = 50 # update players["Dwayne"] = 999 # add new
Loop through dictionary
for username in players: print(username, players[username])
Looping gives you keys — use the key to get the value
LoopsFor & while
For loop (N times)
for n in 8: # n = 0, 1 … 7 print(n)
While loop
while glass < 0.5: glass += randf_range(0.01, 0.2)
Be careful — forgetting to advance the condition = infinite loop crash
Loop control
break # exit loop immediately continue # skip to next iteration
EnumsNamed state tags
enum Alignment { ALLY, NEUTRAL, ENEMY } var unit_alignment = Alignment.ALLY if unit_alignment == Alignment.ENEMY: print("Not welcome!")
Safer than strings — Godot errors on typos. Pairs perfectly with match.
Inspector-editable enum
@export var alignment: Alignment
SignalsNode-to-node events
Define a signal
signal leveled_up(message)
Emit it
leveled_up.emit("GZ!")
Connect via code
leveled_up.connect(_on_leveled_up)
Receiver function
func _on_leveled_up(message): print(message)
Rule of thumb: call down, signal up — parents call children directly; children signal upward
NodesReferencing & modifying
Drag-to-create a reference
$Label.text = "Hello!" $Label.modulate = Color.GREEN
Store as @onready variable
@onready var label = $Label
@onready waits until children exist — avoids null errors
Export a node reference
@export var my_node: Node
Assign any node via the inspector — survives renames
Get / SetIntercept variable changes
Setter — clamp health to 0–100
var health = 100: set(value): health = clamp(value, 0, 100) health_changed.emit(health)
Getter — convert value on read
var chance = 0.2 var chance_pct: int: get: return int(chance * 100) set(value): chance = float(value) / 100
ClassesBlueprints & instances
Define a class
class_name Character @export var profession: String @export var health: int func die(): health = 0 print(profession, " died.")
Use it from another script
@export var target: Character func _ready(): target.die()
Inner class
class Equipment: var armor = 10 var weight = 5 var chest = Equipment.new()

Indentation is required

Scope
Variables declared at the top of a script are accessible everywhere. Variables declared inside a function only exist inside that function.
