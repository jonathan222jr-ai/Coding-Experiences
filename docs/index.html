ML-Guided Profile Optimization

Undergraduate research into whether an LLM agent can read GPU memory profiles and propose optimizations a human would.

  • Parses DrGPUM profiler output, identifies kernel hotspots, and ranks concrete fixes by impact against effort
  • Three chained agent skills — analyze the profile, suggest the fix, then verify the speedup is real and the bottleneck actually moved
  • Persistent memory across runs plus token accounting to keep experiments cheap
